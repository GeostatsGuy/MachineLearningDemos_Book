Definition of Recursion#

Recursive neural networks are built upon the concept of recusion. Let’s start by defining recursion,

From Oxford English Dictionary,

  • Recursion - “the repeated application of a recursive procedure or definition”

Recursion is a recursive procedure, is a recursive procedure, is a recursive procedure, …

From Wikipedia,

  • Recursion - “recursion occurs when the definition of a concept or process depends on a simpler or previous version of itself”

Philosophically speaking we can describe recursion as,

  • a complicated system built by repeated application of a simple step.

Let’s take a simple mathematical operator that is solved with recursion, the factorial.

\[ n! = n \cdot n-1 \cdot n-2 \cdot \ldots \cdot 3 \cdot 2 \cdot 1 \]

Here’s a function that could be written in Python to solve any factorial of an integer,

def factorial(n):
    if n == 0 or n == 1:
        return 1:
    else:
        return n * factorial(n-1)

Did you see it? The function calls itself, this is recursion in programming.

Forward Pass Through a Recurrent Neural Network#

Now here is a complete forward pass through our recurrent neural network.

  • start with the first prediction in the sequence, and calculate the hidden layer output only.

  • we don’t have a previous prediction with a hidden layer output, so the common approach is to assume the signal, \(H_2^{t-1}\), as \(H_2^{0}=0.0\)

\[ H_2^1 = \alpha \left( \lambda_{1,2} \cdot I_1^1 + \lambda_{2^{(t-1)},2} \cdot \cancelto{0}{H_2^0} + b_2 \right) \]

  • now let’s proceed to the second prediction in the data series, we can pass the output signal from the first prediction hidden layer, \(H_2^{t-1} = H_2^{1}\) to our current \(t=2\) hidden layer.

\[ H_2^2 = \alpha \left( \lambda_{1,2} \cdot I_1^2 + \lambda_{2^{(t-1)},2} \cdot H_2^1 + b_2 \right) \]

  • now let’s proceed to the third prediction in the data series, we pass the output signal from the first prediction hidden layer, \(H_2^{1}\) to our previous \(H_2^{2}\) hidden layer, combine these signals and pass this hidden layer output to the current hidden layer and combine with the current data to calculate the output of the current hidden layer node, \(H_2^{3}\)

\[ H_2^3 = \alpha \left( \lambda_{1,2} \cdot I_1^3 + \lambda_{2^{(t-1)},2} \cdot H_2^2 + b_2 \right) \]

No let’s combine these euqations together to show the combination of the previous data in the sequence to the current prediction. Substituting the equation for \(H_2^2\),

\[ H_2^3 = \alpha \left( \lambda_{1,2} \cdot I_1^3 + \lambda_{2^{(t-1)},2} \cdot \alpha \left( \lambda_{1,2} \cdot I_1^2 + \lambda_{2^{(t-1)},2} \cdot H_2^1 + b_2 \right) + b_2 \right) \]

and substituting the equation for \(H_2^1\),

\[ H_2^3 = \alpha \left( \lambda_{1,2} \cdot I_1^3 + \lambda_{2^{(t-1)},2} \cdot \alpha \left( \lambda_{1,2} \cdot I_1^2 + \lambda_{2^{(t-1)},2} \cdot \alpha \left( \lambda_{1,2} \cdot I_1^1 + \lambda_{2^{(t-1)},2} \cdot \cancelto{0}{H_2^0} + b_2 \right) + b_2 \right) + b_2 \right) \]

We continue until we have calculated the output for all our hidden layers for each of our predictions in the series.

  • we have finished integrating the recursive aspect of our neural network.

Now we can proceed along the hidden layer to output layer connections to the output node and then pass through the output node to calculate the prediction at each step in our series data.

The pre-activation in the output node is,

\[ O_{3_{in}} = \lambda_{2,3} \cdot H_2 + b_3 \]

and since for regression we commonly use identity activation,

\[ O_3 = \alpha(O_{3_{in}}) = O_{3_{in}} \]

Training Neural Networks Steps#

Training an artificial neural network proceeds iteratively by these steps,

  1. initialized the model parameters

  2. forward pass to make a prediction

  3. calculate the error derivative based on the prediction and truth over training data

  4. backpropagate the error derivative back through the artificial neural network to calculate the derivatives of the error over all the model weights and biases parameters

  5. update the model parameters based on the derivatives and learning rates

  6. repeat until convergence.

Here’s some details on each step,

  1. Initializing the Model Parameters - initialize all model parameters with typically small (near zero) random values.

  2. Forward Pass - see the workflow in the previous section for the forward pass through our recurrent neural network.

  3. Calculate the Error Derivative - given a loss of,

\[ L = \frac{1}{2} \left(\hat{y}(\bf{u}_t) - y(\bf{u}_t) \right)^2 \]

     and the error derivative, i.e., rate of change of in error given a change in model estimate is,

\[ \frac{\partial L}{\partial \hat{y}(\bf{u}_t)} = \hat{Y} - Y \]

     For now, let’s only consider a single estimate, and we will address more than 1 training data later.

  1. Backpropagate the Error Derivative - we shift back through the artificial neural network to calculate the derivatives of the error over all the model weights and biases parameters, with the chain rule, for example the loss derivative backpropagated to the output of node \(H_4\),

\[ \frac{\partial L}{\partial H_2} = \frac{\partial O_{3_{\text{in}}}}{\partial H_2} \cdot \frac{\partial O_3}{\partial O_{3_{\text{in}}}} \cdot \frac{\partial L}{\partial O_3} = \lambda_{2,3} \cdot \bigl( (1 - O_3) \cdot O_3 \bigr) \cdot (O_3 - y(\bf{u}_t)) \]

  1. Update the Model Parameters - based on the derivatives, \(\frac{\partial L}{\partial \lambda_{i,j}}\) and learning rates, \(\eta\), like this,

\[ \lambda_{i,j}^{\ell} = \lambda_{i,j}^{\ell - 1} + \eta \cdot \frac{\partial L}{\partial \lambda_{i,j}} \]

  1. Repeat Until Convergence - return to step 1, until the error, \(L\), is reduced to an acceptable level, i.e., model convergence is the condition to stop the iterations

These are the steps, now let’s dive into the details for each.

Let’s start with calculating the loss derivative.

Calculating the Loss Derivative#

Backpropagation is based on the concept of allocating or propagating the loss derivative backwards through the neural network,

  • we calculate the loss derivative and then distribute it sequentially, in reverse direction, from network output back towards the network input

  • it is important to know that we are working with derivatives, and that backpropagation is NOT distributing error, although as you will see it may look that way!

We start by defining the loss, given the truth, \(𝑦\), and our prediction, \(\hat{y} = O_3\), we calculate our \(L^2\) loss as,

\[ L = \frac{1}{2} \left( \hat{y}(\bf{u}_t) - y(\bf{u}_t) \right)^2 \]

our choice of loss function allows us to use the prediction error as the loss derivative! We calculate the loss derivative as the partial derivative of the loss with respect to the estimate, \(\frac{\partial 𝐿}{\partial \hat{y}}\),

\[ \frac{\partial \mathcal{L}}{\partial \hat{y}(\bf{u}_t)} = \frac{\partial \frac{1}{2} \left( \hat{y}(\bf{u_t}) - y(\bf{u}_t) \right)^2 }{\partial \hat{y}(\bf{u}_t)} = \hat{y}(\bf{u}_t) - y(\bf{u}_t) \]

We are backpropagating the loss derivative, but due to our formulation of the \(L^2\) loss, we only have to calculate the error at our output node output, but once again - it is the loss derivative.

For the example of our simple artificial neural network with the output at node, \(O_3\), our loss derivative is,

\[ \frac{\partial \mathcal{L}}{\partial O_3} = \frac{\partial \mathcal{L}}{\hat{y}} = \hat{y}(\bf{u}_t) - y(\bf{u}_t) = O^t_3 - y(\bf{u}_t) \]

So this is our loss derivative backpropagated to the output our output node, and we are now we are ready to backpropagate this loss derivative through our artificial neural network, let’s talk about how we step through nodes and along connections.

Backpropagation through Output Node with Identity Activation#

Let’s backpropagate through our output node, \(O^t_3\), from post-activation to pre-activation. To do this we need the partial derivative our activation function.

  • since this is an output node with a regression artificial neural network I have selected the identity or linear activation function.

The identity activation at output node \(O_6\) is defined as:

\[ O^t_3 = \sigma(O^t_{3_{in}}) = O_3 \]

The derivative of the identity activation at node \(O_3\) with respect to its input \(O_{3_{in}}\), i.e., crossing node \(O_3\) is,

\[ \frac{\partial O_3}{\partial O_{3_{in}}} = \frac{\partial \left(O_{3_{in}} \right)}{\partial O_{3_{in}}} = 1.0 \]

Note, we just need \(O_3\) the output signal from the node. Now we can add this to our chain rule to backpropagate from loss derivative with respect to the node output, \(\frac{\partial \mathcal{L}}{\partial O_3}\), and to the loss derivative with respect to the node input, \(\frac{\partial \mathcal{L}}{\partial O_{3_{\text{in}}}}\),

\[ \frac{\partial \mathcal{L}}{\partial O_{3_{\text{in}}}} = \frac{\partial O^t_3}{\partial O^t_{3_{\text{in}}}} \cdot \frac{\partial \mathcal{L}}{\partial O^t_3} = 1.0 \cdot (O^t_3 - y(\bf{u}_t)) \]

Now that we have backpropagated through an output node, let’s backpropagation along the \(H_2\) to \(O_3\) connection from the hidden layer.

Backpropagation along Connections#

Now let’s backpropagate along the connection between output node \(O_3\) and and the hidden layer node \(H_2\).

Preactivation, the input to node \(O_3\) is calculated as,

\[ O^t_{3_{\text{in}}} = \lambda_{2,3} \cdot H^t_2 + b_3 \]

We calculate the derivative along the connection as,

\[ \frac{\partial O^t_{3_{\text{in}}}}{\partial H^t_2} = \frac{\partial}{\partial H_2} \left( \lambda_{2,3} \cdot H^t_2 + b_3 \right) = \lambda_{4,6} \]

by resolving the above partial derivative, we see that backpropagation along a connection by applying the connection weight.

\[ \frac{\partial O^t_{3_{\text{in}}}}{\partial H^t_2} = \lambda_{2,3} \]

Note, we just need the current connection weight \(\lambda_{2,3}\). Now we can add this to our chain rule to backpropagate along the \(H_2\) to \(O_3\) connection from loss derivative with respect to the output layer node input \(\frac{\partial \mathcal{L}}{\partial O_{3_{\text{in}}}}\), to the loss derivative with respect to the hidden layer node output \(\frac{\partial \mathcal{L}}{\partial H_2}\).

\[ \frac{\partial \mathcal{L}}{\partial H_2} = \frac{\partial O^t_{3_{\text{in}}}}{\partial H_2} \cdot \frac{\partial O^t_3}{\partial O^t_{3_{\text{in}}}} \cdot \frac{\partial \mathcal{L}}{\partial O^t_3} = \lambda_{2,3} \cdot 1.0 \cdot (O^t_3 - y(\bf{u}_t)) \]

def initialize_lstm_weights(seed=None, scale=0.5):
    """
    Initialize weights and biases for a single-node LSTM.
    Returns a dictionary of parameters.
    """
    rng = np.random.default_rng(seed)
    params = {
        "w1f":  rng.uniform(-scale, scale),  # input → forget gate
        "w2tf": rng.uniform(-scale, scale),  # hidden (t-1) → forget gate
        "bf":   rng.uniform(-scale, scale),  # forget gate bias

        "w1i":  rng.uniform(-scale, scale),  # input → input gate
        "w2ti": rng.uniform(-scale, scale),  # hidden (t-1) → input gate
        "bi":   rng.uniform(-scale, scale),  # input gate bias

        "w1c":  rng.uniform(-scale, scale),  # input → candidate
        "w2tc": rng.uniform(-scale, scale),  # hidden (t-1) → candidate
        "bc":   rng.uniform(-scale, scale),  # candidate bias

        "w1o":  rng.uniform(-scale, scale),  # input → output gate
        "w2to": rng.uniform(-scale, scale),  # hidden (t-1) → output gate
        "bo":   rng.uniform(-scale, scale),  # output gate bias

        "w23":  rng.uniform(-scale, scale),  # hidden → output
        "b3":   rng.uniform(-scale, scale),  # output bias
    }
    return params

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def sigmoid_deriv(h):
    return h * (1 - h)

def tanh_deriv(h):
    return 1 - h**2

def forward_pass(x, params):
    """
    Forward pass through a single-node LSTM.
    """
    (
        w1f, w2tf, bf,
        w1i, w2ti, bi,
        w1c, w2tc, bc,
        w1o, w2to, bo,
        w23, b3
    ) = params.values()

    T = len(x)

    # gates and states
    f, i, c_tilde, o = np.zeros(T), np.zeros(T), np.zeros(T), np.zeros(T)
    a_f, a_i, a_c, a_o = np.zeros(T), np.zeros(T), np.zeros(T), np.zeros(T)
    c2, h2 = np.zeros(T), np.zeros(T)
    y_pred = np.zeros(T)

    for t in range(T):

        h_prev = 0.0 if t == 0 else h2[t-1]
        c_prev = 0.0 if t == 0 else c2[t-1]

        # forget gate
        a_f[t] = w1f * x[t] + w2tf * h_prev + bf
        f[t] = sigmoid(a_f[t])

        # input gate
        a_i[t] = w1i * x[t] + w2ti * h_prev + bi
        i[t] = sigmoid(a_i[t])

        # candidate memory
        a_c[t] = w1c * x[t] + w2tc * h_prev + bc
        c_tilde[t] = np.tanh(a_c[t])

        # cell state
        c2[t] = f[t] * c_prev + i[t] * c_tilde[t]

        # output gate
        a_o[t] = w1o * x[t] + w2to * h_prev + bo
        o[t] = sigmoid(a_o[t])

        # hidden state
        h2[t] = o[t] * np.tanh(c2[t])

        # prediction
        y_pred[t] = w23 * h2[t] + b3

    return (
        y_pred,
        h2,
        c2,
        f,
        i,
        c_tilde,
        o,
        a_f,
        a_i,
        a_c,
        a_o
    )

def mse_loss(y_pred, y):
    return np.mean((y_pred - y)**2)

def backward_pass(x, y, y_pred, h2, c2, f, i, c_tilde, o,
                  a_f, a_i, a_c, a_o, params):
    """
    Backward pass through a single-node LSTM.
    """
    (
        w1f, w2tf, bf,
        w1i, w2ti, bi,
        w1c, w2tc, bc,
        w1o, w2to, bo,
        w23, b3
    ) = params.values()

    T = len(x)

    # initialize gradients
    grads = {k: 0.0 for k in params.keys()}

    # gradients passed backward through time
    delta_h_next = 0.0
    delta_c_next = 0.0

    for t in reversed(range(T)):

        h_prev = 0.0 if t == 0 else h2[t-1]
        c_prev = 0.0 if t == 0 else c2[t-1]

        # loss derivative wrt y_pred[t]
        dL_dy = 2 * (y_pred[t] - y[t]) / T

        # ------------------------------------------------
        # output layer
        # ------------------------------------------------
        grads["w23"] += dL_dy * h2[t]
        grads["b3"]  += dL_dy

        # gradient arriving at h_t
        delta_h = dL_dy * w23 + delta_h_next

        # ------------------------------------------------
        # h_t = o_t * tanh(c_t)
        # ------------------------------------------------
        tanh_c = np.tanh(c2[t])

        delta_o = delta_h * tanh_c
        delta_c = delta_h * o[t] * (1 - tanh_c**2)

        # gradient flowing from future cell state
        delta_c += delta_c_next

        # ------------------------------------------------
        # output gate
        # ------------------------------------------------
        delta_a_o = delta_o * sigmoid_deriv(o[t])

        grads["w1o"]  += delta_a_o * x[t]
        grads["w2to"] += delta_a_o * h_prev
        grads["bo"]   += delta_a_o

        # ------------------------------------------------
        # cell state:
        #
        # c_t = f_t*c_prev + i_t*c_tilde
        # ------------------------------------------------

        # forget gate
        delta_f = delta_c * c_prev
        delta_a_f = delta_f * sigmoid_deriv(f[t])

        grads["w1f"]  += delta_a_f * x[t]
        grads["w2tf"] += delta_a_f * h_prev
        grads["bf"]   += delta_a_f

        # input gate
        delta_i = delta_c * c_tilde[t]
        delta_a_i = delta_i * sigmoid_deriv(i[t])

        grads["w1i"]  += delta_a_i * x[t]
        grads["w2ti"] += delta_a_i * h_prev
        grads["bi"]   += delta_a_i

        # candidate
        delta_c_tilde = delta_c * i[t]
        delta_a_c = delta_c_tilde * tanh_deriv(c_tilde[t])

        grads["w1c"]  += delta_a_c * x[t]
        grads["w2tc"] += delta_a_c * h_prev
        grads["bc"]   += delta_a_c

        # ------------------------------------------------
        # pass gradients to previous time step
        # ------------------------------------------------

        delta_h_next = (
            delta_a_f  * w2tf +
            delta_a_i  * w2ti +
            delta_a_c  * w2tc +
            delta_a_o  * w2to
        )

        delta_c_next = delta_c * f[t]

    return grads

def update_weights(params, grads, lr=0.001):
    """
    Update LSTM weights using gradient descent.

    params : dict
        Current weights and biases
    grads : dict
        Gradients for each parameter
    lr : float
        Learning rate
    """
    updated_params = {}

    for k in params:
        updated_params[k] = params[k] - lr * grads[k]

    return updated_params
